# WinPulse 7.1 Rebuild

WinPulse помогает подобрать настройки Windows под конкретный ПК, посмотреть ограничения для железа и сравнить результат до и после изменений. В интерфейсе WPF доступны шесть режимов, конструктор и каталог из 69 блоков с 292 операциями. Все настройки были проверены лично на пк автора.

## Первый запуск

1. Скачай из GitHub Releases архив **WinPulse-7.1-win-x64.zip** и распакуй целиком, например в `C:\WinPulse`. Рядом с EXE должны лежать `winpulse.bat`, `lib` и `Main`.
2. Открой **WinPulse.exe**. Проверь определённое железо в «Обзоре». В «Начале работы» раскрой состав режима, а в каталоге посмотри, что меняет каждый блок.
3. Перед применением проверь план в консольной песочнице командой `.\winpulse.bat /dryrun`. Для реальных изменений движок запрашивает повышение прав. Сохрани папку Backups после сеанса, она нужна для отката.

Для Windows 10 22H2 и Windows 11 x64. Рекомендуется .NET Framework 4.8 или новее, требуется Windows PowerShell 5.1. Перед применением включи защиту системы на системном томе. Изменения загрузчика и настроек безопасности требуют отдельного внимания. Для удаления пакетов и очистки файлов есть ограничения отката. Подробнее в [руководстве](README.txt).

## Сборка и проверка

Запускай из корня исходников на Windows x64. Для сверки каталогов нужен Python 3, для сборки — Windows PowerShell и компилятор из .NET Framework. Скрипт проверяет наличие сборочных компонентов.

```powershell
python AUDIT.py
python build_help.py --check
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Desktop\build.ps1
(Start-Process .\WinPulse.exe -ArgumentList '--dry-run' -Wait -PassThru).ExitCode
```

Код 0 означает, что автономная проверка интерфейса прошла. Для интерактивного предпросмотра запусти `.\WinPulse.exe --dry-run --ui`. После правок исходной документации обнови HTML и каталог командой `python build_help.py`.
